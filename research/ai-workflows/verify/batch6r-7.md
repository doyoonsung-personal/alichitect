- **Model Studio region and inference scope are different:** the region controls access and storage; deployment scope controls inference location. API keys and model lists are region-specific. [Source](https://www.alibabacloud.com/help/en/model-studio/regions)
- **Embedding request batches are distinct from Batch Inference.** The v4 model card marks Batch Inference unsupported, despite accepting multiple texts per request. [Source](https://www.alibabacloud.com/help/en/model-studio/text-embedding-v4)
- **AgentLoop has additional costs:** dataset storage and separately billed dependencies, including ARMS and SLS. The two quoted rates are not a complete cost estimate. [Source](https://www.alibabacloud.com/help/en/agentloop/product-overview/agentloop-billing-overview)
- **Budget limits exclude training, PTU and DTU charges.** Auto-stop returns 429 errors; Alibaba advises against enabling it for production environments. [Source](https://www.alibabacloud.com/help/en/model-studio/budget-management)
