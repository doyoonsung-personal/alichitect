# NDJSON op grammar v2 for streaming diagram edits
# Research output, checked 2026-10-31. Facts paraphrased; verify before relying on prices or regions.

## OP GRAMMAR v2 (NDJSON: one compact JSON object per line, plain-text response, no response_format, no tools)
{"t":"say","text":"<=25 words, user's language"}
{"t":"plan","products":["esa","waf","alb","ecs","polardb"],"note":"<=12 words"}   (optional FIRST line; client shows ghost nodes + fills product panel; unmeasured)
{"t":"group","id":"vpc-main","kind":"external|edge|region|vpc|zone|subnet|onprem","label":"...","parent":"<group id>|null"}   (network/location containers only)
{"t":"node","id":"app","product":"<catalog id>","label":"...","group":"<group id>|null","zones":["a","b"],"why":"<=20 words"}   (UPSERT by id; zones = one logical node spanning AZs)
{"t":"edge","id":"e-app-db","from":"app","to":"db","label":"<=3 words","kind":"data|async|control|resolve"}
{"t":"insert","id":"waf","product":"waf","label":"WAF","why":"...","on":"e-esa-alb"}   (client splits edge on: esa->waf->alb, keeps old label on first segment)
{"t":"move","id":"<node|group id>","to":"<group id>|null"}
{"t":"remove","id":"<node|edge|group id>"}   (node removal cascades its edges; unknown id = no-op)
{"t":"rec","product":"qoder","fit":"primary|complement","why":"<=20 words"}   (product-need answers; edges between recs allowed)
{"t":"gap","need":"...","note":"why no catalog product fits"}
{"t":"done","summary":"one sentence"}
## SYSTEM PROMPT RULES (extend probe.mjs RULES)
R1 Output ONLY NDJSON, one compact object per line; no markdown, fences or prose.
R2 Order: [plan] then per section: say, group, nodes, edges; outside-in users->edge->region->VPC->compute->data->async->managed/ops/security; declare before use.
R3 product = CATALOG id only; otherwise emit gap.
R4 Never put placement=region|global|edge|saas services in vpc/zone groups (client draws them in the region lane).
R5 DNS is never in the data path: users->dns kind "resolve"; traffic goes users->first edge service.
R6 North-south order follows catalog rank: ESA/CDN(1) -> Anti-DDoS(2) -> WAF(3) -> ALB/NLB/API GW(4) -> compute(5) -> data(6).
R7 Multi-AZ: one node with zones:[...], never one node per zone.
R8 Follow-ups: CURRENT DIAGRAM is authoritative; emit minimal ops only; reuse ids; to put a component into an existing path use insert; removing a node removes its edges (do not list them); never re-emit unchanged elements; if the request is already satisfied, say so + done.
R9 Product-need questions -> rec ops (+edges between recs), no groups.
R10 say/why/label in the user's language; product names come from the catalog.
## CATALOG ROW (prompt) and METADATA (server)
prompt row: id | official name | category | placement | rank | purpose<=12 words | pairs-with ids   (~40-60 tok; 300 rows ~12-18k tok)
server JSON: {id,name,aliases[],category,placement:external|global|edge|region|vpc|saas,allowedIn:[group kinds],pathRank?:1-6,icon,docsUrl,blurb}
## REQUESTS
draw/edit: POST https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions {"model":"qwen3.8-max","stream":true,"stream_options":{"include_usage":true},"enable_thinking":false,"max_completion_tokens":4096,"messages":[{"role":"system","content":[{"type":"text","text":"<RULES+CATALOG>","cache_control":{"type":"ephemeral"}}]}, ...compactHistory, {"role":"user","content":"CURRENT DIAGRAM:\n<compact graph JSON, no why>\n\n<ask>"}]}
repair (max 1, thinking off): same + user content "VALIDATOR FINDINGS:\n- <code> <ids> <msg>\nFix only these with minimal ops."
review (opt-in): "enable_thinking":true,"thinking_budget":1536 (1024 measured: 243 reasoning tok, first op 7.5 s); stream reasoning_content to a collapsed console block.
AI SDK: providerOptions.alibaba.enableThinking=false is mandatory (provider omits the flag; server default ON).
fallback model: qwen3.7-max (SG 600 RPM / 1M TPM, $2.5/$7.5 per M).
keep-warm: same cached system prefix + ask 'Reply {"t":"done","summary":"ok"}' every <=4.5 min (explicit cache TTL 5 min, resets on hit).
## SERVER -> BROWSER SSE (POST + fetch ReadableStream, not EventSource)
event: meta {turnId,model} | event: say {sayId,delta,final} (stream chars by partially parsing the current say line) | event: op {seq,op} | event: repair {seq,op,rule} | event: warn {code,ids,msg} | event: thinking {delta} (review only) | event: usage {prompt_tokens,cached_tokens,completion_tokens} | event: done {summary,stats} | event: error {code,retryable} | ': ping' comment after 15 s of silence
headers: Content-Type: text/event-stream; Cache-Control: no-cache, no-transform; X-Accel-Buffering: no; FC detects streaming via Transfer-Encoding: chunked
## VALIDATOR (per op, then at done)
L1 syntax: per-line JSON.parse; skip ``` and blank lines; regex-extract {...}; jsonrepair for near-misses; else drop + warn
L2 schema: zod discriminatedUnion('t'); id /^[a-z0-9][a-z0-9-]{0,40}$/; label<=40 chars; why<=160 chars; cap 300 nodes per graph
L3 refs: unknown product -> alias map -> else gap node; edge before node -> pending buffer (flush when node arrives); unresolved at done -> drop + warn; missing parent -> root; duplicate node id -> upsert
L4 semantic: W-containment -> auto-move to region lane / re-parent group (replay: F 7, G 10, H 2, E 2 -> 0 left); W-dns-in-data-path -> kind:resolve; W-replica-asymmetry -> zones attr or mirror edges; W-path-order -> repair turn
L5 one repair turn (thinking off) for unresolved E/W; accept otherwise
## WATCHDOGS / LIMITS
first byte 12 s (warm 1.0-2.8 s; cold 24k 13.9 s) -> abort, retry once -> fallback model | idle 20 s | turn cap 120 s (diagram 35-41 s) | host max duration >=300 s | heartbeat 15 s (Cloudflare proxy read timeout 125 s) | abort upstream when the user sends a new message
